# Scoring Rubric

Score on **two separate axes** out of 10 each. Never blend into one number — they measure different things and a CV can be strong on one, weak on the other.

## Axis 1 — JD/Keyword Match (mechanical, ATS-style)

| Score | Criteria |
|---|---|
| 10 | Nearly all JD must-have skills/keywords present in genuinely-held experience; seniority level, years of experience, and domain all align closely |
| 7–9 | Most must-haves present; one or two minor gaps or a slight seniority mismatch |
| 5–6 | Roughly half of must-haves present; noticeable gaps in domain or experience depth |
| 3–4 | Significant mismatch — several core requirements have no genuine match |
| 1–2 | Fundamentally different role/domain/seniority |

Score this by literally checking each JD requirement against the master profile — list which are met, which aren't. Do not round up because the candidate "seems senior enough" — check the specifics.

## Axis 2 — CV Quality (human-reviewer standard)

| Criterion | What "strong" looks like |
|---|---|
| Achievement framing | Bullets show outcome/impact, not just duties — quantified where the profile has real numbers |
| Structure/clarity | Logical order, no redundancy, easy to scan in <30 seconds per section |
| Relevance ordering | Most JD-relevant experience surfaced first/prominently, not buried |
| Conciseness | Fits 2-page cap without cramming; no filler phrases |
| Consistency | Tense, formatting, and terminology consistent throughout |

Score 1–10 based on how many of these hold strongly. A CV that's accurate but generic (no quantified impact, buried relevant experience) should score in the 5–7 range, not 9+, even if nothing is factually wrong.

## Reporting to the user

Always show:
1. Both scores separately, with 1–2 lines on what's driving each
2. The **gap list** — JD requirements not genuinely met, stated plainly (not hidden inside a high score)
3. If a 9+ isn't achievable without fabrication, say so directly rather than inflating either score

## Guardrail

A high score must never be achieved by inventing content. If the ceiling on Axis 1 is genuinely capped by real gaps in the candidate's background, that's the honest answer — report it as such.

## Score gate (SKILL.md Step 5)

Before generating the tailored CV document, project both axis scores from the JD-vs-profile analysis alone. If either projects below **8/10**, stop and report the projection plus the gap list instead of producing the document — don't spend effort generating a polished CV for a fit that was never going to score well. Proceed to full generation only if both project to 8+, or the user explicitly says they want the CV anyway despite the projected score.
